# rustrefjp - Rust言語非公式日本語ドキュメント

rustrefjp は、Rust 標準ライブラリおよび関連仕様について、AIによってリファレンスを翻訳していくプロジェクトです。
AIによって作られた翻訳は、レビュアーが細心の注意を以て確認しています。
